# Consulta de comissão de vendedores

Após finalizar as vendas no sistema, é possível consultar a comissão dos vendedores através do módulo **Administrador**.

## Acessando a rotina

Acesse:

**Administrador → Consultas → Financeiro → Comissão**

Será exibida a tela de filtros para consulta das comissões.

## Filtrando o período

Informe o período desejado para a consulta.

Exemplo:

- Mês de referência da comissão.

Após definir o período, clique no ícone de **Engrenagem** para configurar as regras.

## Configurando as regras

Na tela de configuração:

- Deixe marcada apenas a opção **Regras de Venda**.

Após confirmar, clique no botão **Play (Processar)**.

O sistema calculará as comissões e apresentará os vendedores.

## Informações apresentadas

Na consulta serão exibidos:

- Vendedor;
- Percentual de comissão;
- Valor da comissão.

## Consultando os detalhes

A tela permite visualizar diversos detalhes através das teclas de atalho.

### F2 - Notas fiscais

Exibe todas as notas fiscais utilizadas no cálculo da comissão do vendedor.

### F3 - Clientes

Mostra todos os clientes atendidos pelo vendedor no período consultado.

### F4 - Produtos

Exibe os produtos vendidos pelo vendedor.

### F6 - Regras de saída

Permite visualizar quais regras de saída foram utilizadas nas vendas.

## Exportando o relatório

Caso deseje compartilhar ou arquivar a consulta:

1. Clique em **Imprimir**.
2. Escolha a opção para salvar o relatório em **PDF**.

## Relatório de vendas

Também é possível consultar as vendas através do relatório de faturamento.

Acesse:

**Relatórios → Faturamento → Resumo de Vendas**

Informe:

- Período desejado;
- Modelo **Sintético**, caso queira um relatório mais resumido.

## Tipos de agrupamento

O relatório permite agrupar as informações por:

- Tipo de saída;
- Produto;
- Nota fiscal;
- Vendedor.

## Filtrando apenas vendas

Para listar apenas as vendas, utilize os códigos de regra:

- **501**
- **502**
- **601**

Esses códigos podem ser informados no campo **Tipo de Saída**.

Após configurar uma vez, o sistema manterá esse filtro salvo para as próximas consultas.

## Consultando por nota

Selecionando o agrupamento **Por Nota**, será possível visualizar:

- Número da nota;
- Valor;
- Quantidade;
- Série;
- Demais informações da venda.

## Consultando por vendedor

Selecionando o agrupamento **Por Vendedor**, o sistema exibirá um resumo das vendas realizadas por cada vendedor.

Caso deseje consultar apenas um vendedor específico:

1. Clique nos **três pontos** do campo **Vendedor**.
2. Selecione o vendedor desejado.
3. Gere o relatório.

Esse relatório pode ser enviado diretamente ao vendedor para conferência de suas vendas e comissão.

## Consultando as regras de venda

Caso tenha dúvidas sobre quais códigos representam vendas, acesse:

**Livros Fiscais → Cadastro de Regras**

Nessa rotina é possível consultar:

- Regras de venda;
- Regras de venda sem nota;
- Regras de bonificação;
- Demais regras fiscais utilizadas pelo sistema.

:::tip
Sempre utilize apenas as regras de venda (501, 502 e 601, quando aplicável) ao calcular a comissão. Dessa forma, o relatório apresentará somente as vendas que realmente geram comissão.
:::

:::tip
Por fim, caso tenha dúvidas ou não consiga concluir o processo, entre em contato com o suporte da Infolight.
:::
