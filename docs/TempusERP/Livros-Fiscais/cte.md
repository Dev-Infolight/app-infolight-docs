# Lançamento de CT-e de entrada

O lançamento do Conhecimento de Transporte Eletrônico (CT-e) é utilizado para registrar os custos de frete vinculados às notas fiscais de entrada.

## Acessando a rotina

Acesse:

**Livros Fiscais → Movimento → Entrada de Frete**

## Informando a transportadora

No campo **Fornecedor**, selecione a transportadora responsável pelo frete.

Caso ela ainda não esteja cadastrada:

- Clique em **Incluir**;
- Cadastre a transportadora utilizando os dados constantes no CT-e.

## Preenchendo os dados do CT-e

Informe os seguintes dados:

- Série do CT-e;
- Número do CT-e;
- Data de emissão;
- Data de lançamento;
- Valor do frete.

## Rateio do frete

Na opção de rateio, utilize:

- **Ratear pelos itens da Nota Fiscal**

Essa é a forma mais utilizada, pois o sistema distribuirá automaticamente o valor do frete entre todos os itens das notas vinculadas.

## Selecionando a regra fiscal

Escolha a regra de entrada correspondente:

- Aquisição de frete com ICMS;
- Aquisição de frete sem ICMS.

A definição depende do próprio CT-e:

- Se houver destaque de ICMS, utilize a regra **com ICMS**;
- Caso contrário, utilize a regra **sem ICMS**.

## Vinculando as notas fiscais

Clique no botão **NFe** para selecionar as notas fiscais relacionadas ao frete.

Adicione todas as notas transportadas por aquele CT-e.

Caso tenha incluído alguma nota incorretamente, basta removê-la antes de concluir.

Após finalizar a seleção, clique em **Concluir**.

## Informando o vencimento

Na parte financeira, informe:

- Data de vencimento;
- Valor da parcela.

### Parcelamento

Caso o frete seja parcelado:

1. Informe o valor da primeira parcela.
2. Pressione a seta para baixo para criar a próxima parcela.
3. Informe o próximo vencimento.
4. Informe o valor da nova parcela.

Repita esse processo até que a soma das parcelas seja igual ao valor total do CT-e.

## Forma de pagamento

Pressione **F3** no campo **Forma de Pagamento** e selecione a forma correspondente.

Exemplos:

- Boleto;
- PIX;
- À vista.

Caso existam várias parcelas, informe a forma de pagamento de cada uma delas.

## Validando o lançamento

Após preencher todas as informações:

1. Clique em **Validar**.
2. Confirme a operação.

## Conferindo o lançamento

Após salvar, localize o lançamento na rotina de entrada de fretes.

Os CT-es serão identificados pelo **Modelo 57**.

Ao visualizar o documento, será possível verificar que o sistema realizou automaticamente o rateio do frete entre todos os itens das notas fiscais vinculadas.

## Informando a chave de acesso

Para finalizar o processo:

1. Clique no botão **Chave**.
2. Informe ou carregue a chave de acesso do CT-e.
3. Clique em **Gravar**.

Com isso, o lançamento do CT-e estará concluído.

:::tip
Sempre confira se todas as notas fiscais transportadas foram vinculadas ao CT-e antes de finalizar o lançamento. Isso garante que o rateio do frete seja realizado corretamente.
:::

:::tip
Por fim, caso tenha dúvidas ou não consiga concluir o processo, entre em contato com o suporte da Infolight.
:::
