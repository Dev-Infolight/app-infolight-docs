# Simulação da meta de produção

Após criar a **Meta de Venda**, o próximo passo é realizar a simulação da **Meta de Produção**.

Essa rotina permite calcular a quantidade de produtos que deverá ser produzida para atender à meta estabelecida, além de identificar a necessidade de matérias-primas e insumos.

## Acessando a rotina

Acesse:

**Controle de Produção → Metas de Produção → Simular Meta de Produção**

Ao abrir a tela, serão exibidas algumas opções para iniciar o processo.

---

# Opções disponíveis

Nesta rotina estão disponíveis os seguintes botões:

- **Abrir Ordem de Produção Existente**
  - Abre uma ordem de produção já criada anteriormente.

- **Limpar Tela**
  - Limpa as informações da tela para iniciar uma nova simulação.

- **Importar Metas**
  - Importa uma meta de venda já cadastrada para gerar a simulação de produção.

- **Importar Pedido de Venda**
  - Permite gerar a produção diretamente a partir dos pedidos de venda.

---

# Importando a meta de venda

Clique em **Importar Metas**.

O sistema exibirá a lista das metas cadastradas.

Selecione a meta criada anteriormente e clique em **OK**.

Após a importação, todas as informações da meta serão carregadas na tela.

---

# Simulando a produção

Com a meta carregada, clique em **Iniciar**.

Em seguida, clique em **Simular**.

O sistema calculará automaticamente a quantidade de produtos que deverá ser produzida para atender à meta de vendas.

---

# Relatório de necessidade de materiais

A rotina também disponibiliza o botão **Imprimir**.

Esse relatório apresenta a necessidade de matérias-primas e insumos para atender à produção prevista.

Com essas informações, é possível identificar:

- Materiais que já existem em estoque;
- Insumos que precisam ser adquiridos;
- Quantidades necessárias para atender à produção do mês.

Esse relatório normalmente é encaminhado ao setor de compras para que seja realizado o planejamento de aquisição dos materiais.

---

# Planejamento das compras

Após emitir o relatório de necessidade, o responsável pelas compras poderá:

- Consultar o estoque atual;
- Verificar os materiais disponíveis;
- Identificar os itens que precisam ser comprados;
- Garantir que todos os insumos estejam disponíveis para cumprir a meta de produção.

Esse processo evita falta de materiais durante o período produtivo e auxilia no planejamento da empresa.

---

# Iniciando a ordem de produção

Após conferir todas as informações da simulação, clique em **Iniciar**.

O sistema dará sequência ao processo de geração da Ordem de Produção, utilizando a meta importada como base para o planejamento.

---

## Observações

- A simulação depende de uma Meta de Venda previamente cadastrada.
- Utilize o botão **Importar Metas** para carregar a meta desejada.
- O relatório de necessidade auxilia o setor de compras no planejamento de insumos.
- Antes de iniciar a produção, verifique se há estoque suficiente para atender à demanda.
- Após a conferência, utilize o botão **Iniciar** para dar continuidade ao processo produtivo.

:::tip
Por fim, caso tenha dúvidas ou não consiga concluir o processo, entre em contato com o suporte da Infolight.
:::
