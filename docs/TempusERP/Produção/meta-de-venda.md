# Meta de venda

Antes de iniciar qualquer processo de produção, é necessário gerar a **Meta de Venda**. Essa meta servirá como base para o planejamento da produção, considerando o histórico de vendas e os objetivos definidos para o período.

## Acessando a rotina

Acesse:

**Módulo Administrador → Consultas → Faturamento → Projeção de Vendas**

Nesta tela serão informados o período de referência e o mês para o qual será criada a meta.

---

# Definindo a data base

O campo **Data Base** corresponde ao período que será utilizado como referência para gerar a nova meta.

Normalmente, deve-se selecionar o mês que apresentou o melhor desempenho em vendas.

### Exemplo

Supondo que existam três meses disponíveis:

- Janeiro;
- Fevereiro;
- Março.

Se fevereiro foi o mês com maior faturamento, ele deverá ser utilizado como **Data Base**, pois servirá como espelho para a geração da meta do mês seguinte.

---

# Informando o mês objetivo

No campo **Mês Objetivo**, selecione o mês para o qual deseja criar a meta de vendas.

Esse será o período utilizado posteriormente pelo Controle de Produção para calcular a necessidade de fabricação dos produtos.

---

# Selecionando os vendedores

É possível gerar metas para:

- Todos os vendedores;
- Um vendedor específico.

Para gerar a meta geral da empresa, selecione **todos os vendedores**.

Depois clique em **Iniciar**.

O sistema carregará os dados necessários para a geração da meta.

---

# Selecionando a tabela de preços

Após o carregamento das informações, informe a **Tabela de Preços**.

A tabela de preços é utilizada para que o sistema consiga calcular a **meta financeira**, considerando os preços dos produtos nela cadastrados.

Depois de selecionar a tabela, clique em **Calcular**.

O sistema calculará automaticamente a meta quantitativa baseada nas vendas do período informado como Data Base.

---

# Utilizando a Curva ABC

A rotina também permite projetar crescimento nas vendas através da **Curva ABC**.

É possível definir percentuais de crescimento diferentes para cada classificação de produto.

### Exemplo

- Produtos A: **20%**
- Produtos B: **15%**
- Produtos C: **10%**

Após informar os percentuais, clique novamente em **Calcular**.

O sistema recalculará automaticamente todas as metas dos produtos.

---

# Ajustando as metas manualmente

Os campos de:

- Meta Quantitativa;
- Meta Financeira;

podem ser alterados manualmente.

Caso seja necessário aumentar ou diminuir a meta de algum produto específico, basta editar o valor diretamente na grade.

---

# Salvando a meta

Após revisar as informações:

1. Clique no botão **Salvar** (disquete);
2. Confirme a operação;
3. Verifique se todos os vendedores estão selecionados corretamente;
4. Clique novamente em **Salvar**.

---

# Distribuindo a participação dos vendedores

Após salvar a meta, o sistema exibirá uma janela para definir a participação de cada vendedor na meta criada.

Informe o percentual correspondente para cada vendedor.

> **Importante:** A soma das participações deve totalizar **100%**.

Depois de ajustar os percentuais, clique em **Salvar**.

A meta de venda estará criada e pronta para ser utilizada pelo Controle de Produção.

---

# Próximo passo

Após concluir a criação da meta de vendas, acesse:

**Sistema → Acesso → Controle de Produção**

A partir desse ponto será possível iniciar as rotinas de planejamento e produção.

---

## Observações

- A meta de venda deve ser criada antes de iniciar qualquer processo produtivo.
- Utilize como Data Base o mês com melhor desempenho em vendas.
- A tabela de preços é utilizada para calcular a meta financeira.
- A Curva ABC permite projetar crescimento diferente para cada grupo de produtos.
- As metas podem ser alteradas manualmente antes da gravação.
- A participação dos vendedores deve totalizar exatamente **100%**.

:::tip
Por fim, caso tenha dúvidas ou não consiga concluir o processo, entre em contato com o suporte da Infolight.
:::
