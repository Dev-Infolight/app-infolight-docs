# Finalização da produção

Após concluir a produção dos produtos intermediários, o próximo passo é finalizar a produção do produto acabado, ou seja, o produto final.

## Realizando um novo apontamento

Acesse a rotina de apontamento e:

1. Clique em **Novo Apontamento**.
2. Pressione **Enter** para iniciar.

O sistema permitirá realizar toda a produção de uma única vez.

## Conferindo os insumos

Antes de confirmar a produção, o sistema exibirá a quantidade de insumos planejada para utilização.

Nesse momento é possível:

- Manter as quantidades planejadas;
- Alterar as quantidades, caso tenha ocorrido alguma necessidade durante a produção.

Após a conferência, clique em **Realizar Apontamento**.

O sistema exibirá a mensagem informando que o apontamento foi realizado com sucesso.

## Validando a quantidade produzida

Após realizar o apontamento, é necessário validar a quantidade efetivamente produzida.

> **Importante:** O botão **Validação** está disponível apenas para o produto acabado, pois somente ele movimenta o estoque final.

Ao abrir a validação, o sistema preencherá automaticamente a quantidade planejada.

Exemplo:

- Quantidade planejada: **5.000 unidades**

Entretanto, a quantidade produzida pode ser diferente.

### Produção conforme o planejado

Caso tenham sido produzidas exatamente **5.000 unidades**, basta confirmar essa quantidade.

### Produção menor que o planejado

Se houve perdas durante a fabricação, informe a quantidade realmente produzida.

Exemplo:

- Quantidade produzida: **4.900 unidades**

### Produção maior que o planejado

Caso tenha ocorrido um ganho de produção, informe a quantidade real.

Exemplo:

- Quantidade produzida: **5.100 unidades**

> Sempre informe a quantidade efetivamente produzida. Isso garante que o estoque permaneça correto e evita divergências futuras.

## Salvando a validação

Após informar a quantidade correta:

1. Clique em **Salvar**.
2. Confirme os valores apresentados pelo sistema.

Caso identifique algum erro antes da finalização da produção, ainda é possível retornar à tela de validação e corrigir a quantidade informada.

## Finalizando a produção

Com a validação concluída:

1. Clique em **Finalizar Apontamento**.

O sistema concluirá o processo e exibirá a mensagem de confirmação.

Nesse momento, a produção estará oficialmente encerrada e o estoque será atualizado conforme a quantidade validada.

:::tip
Sempre valide a quantidade real produzida antes de finalizar o apontamento. Essa informação será utilizada para manter o estoque correto e garantir a confiabilidade dos relatórios de produção.
:::

:::tip
Por fim, caso tenha dúvidas ou não consiga concluir o processo, entre em contato com o suporte da Infolight.
:::
