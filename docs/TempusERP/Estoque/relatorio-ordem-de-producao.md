# Relatório de Ordens de Produção

O **Relatório de Ordens de Produção** permite consultar todas as produções realizadas em um determinado período, analisando o custo unitário de cada produto, as quantidades produzidas e as Ordens de Produção (OPs) geradas.

Essa rotina é utilizada principalmente para acompanhar a evolução dos custos de produção e consultar o histórico das produções realizadas.

## Como acessar

Acesse:

**Módulo Estoque → Relatórios → Movimento → Ordens de Produção**

## Consultando a produção de um produto

Para consultar a produção de um produto específico:

1. Informe o período desejado.
2. Selecione o produto.
3. Gere o relatório.

O sistema exibirá todas as Ordens de Produção do produto dentro do período informado.

Para cada produção serão apresentados dados como:

- Data da produção;
- Número da Ordem de Produção (OP);
- Custo unitário do produto naquele momento;
- Quantidade produzida.

Isso permite acompanhar a variação do custo do produto entre diferentes produções.

### Exemplo

Um mesmo produto pode apresentar custos diferentes conforme a data da produção.

Exemplo:

- Produção realizada em **02/06** → custo unitário de **R$ 1,39**;
- Produção realizada em **27/06** → custo unitário de **R$ 1,39**.

Outro produto pode apresentar alteração no custo entre produções diferentes, permitindo identificar a evolução do custo de fabricação ao longo do tempo.

## Consultando todas as produções de um período

Caso não seja informado um produto, o relatório exibirá todas as produções realizadas dentro do período selecionado.

Para cada Ordem de Produção serão apresentados:

- Código do produto;
- Número da OP;
- Data da produção;
- Custo unitário;
- Quantidade produzida.

Essa consulta é útil para acompanhar toda a movimentação da produção em um determinado período.

## Informações apresentadas no relatório

O relatório apresenta, entre outras informações:

- Produto produzido;
- Data da produção;
- Ordem de Produção (OP);
- Custo unitário do produto;
- Quantidade produzida.

Na parte superior do relatório é possível visualizar o **custo unitário** de cada produção, enquanto na parte inferior são apresentadas as **quantidades produzidas** correspondentes.
