# Movimentos Internos

A rotina de **Movimentos Internos** é utilizada para registrar movimentações internas de produtos no estoque.

## Como acessar

Acesse:

**Estoque → Movimentos Internos**

## Como realizar um lançamento

1. Clique em **Incluir**.
2. Selecione o produto que será movimentado.
3. No campo **Tipo de Movimento**, selecione um tipo já existente ou realize um novo cadastro.
4. Caso seja necessário cadastrar um novo tipo, informe o código e grave o cadastro.
5. Após salvar, selecione o tipo de movimento desejado.
6. Informe os demais dados da movimentação, como quantidade e demais campos obrigatórios.
7. Verifique se o campo **Sequência** permanece preenchido durante todo o preenchimento da tela.
8. Após conferir todas as informações, finalize o lançamento.

> **Importante:** O Tipo de Movimento cadastrado deve permanecer disponível para seleção após ser salvo. Da mesma forma, o campo **Sequência** deve permanecer preenchido até a conclusão da movimentação, permitindo finalizar o processo normalmente.

:::tip
Por fim, caso tenha dúvidas ou não consiga concluir o processo, entre em contato com o suporte da Infolight.
:::
