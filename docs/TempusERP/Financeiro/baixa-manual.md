# Baixa manual de títulos a receber

A rotina de **Administração de Contas a Receber** permite realizar a baixa manual de títulos recebidos, consultar títulos em aberto, efetuar baixas parciais, emitir relatórios e estornar recebimentos quando necessário.

## Como acessar

Acesse:

**Módulo Financeiro → Títulos a Receber → Administração de Contas a Receber**

> **Importante:** Títulos recebidos por **boleto bancário** normalmente são baixados automaticamente após a leitura do arquivo de retorno do banco. Utilize esta rotina apenas quando for necessário realizar a baixa manual.

## Localizando um título

Você pode localizar um título utilizando:

- Número do título;
- Código do cliente;
- Razão social;
- Vendedor;
- Rota.

Caso não saiba essas informações:

1. Clique em **Parâmetros**.
2. Informe os filtros desejados.
3. Selecione se deseja visualizar:
   - Todos os títulos;
   - Apenas títulos em aberto.
4. Clique em **OK**.

O sistema exibirá todos os títulos de acordo com o período e filtros informados.

## Realizando a baixa manual

Após localizar o título:

1. Selecione o título.
2. Clique em **Baixar**.
3. Informe:
   - Banco ou conta onde o pagamento foi recebido;
   - Data do pagamento;
   - Histórico (opcional);
   - Valor recebido.

Caso o cliente tenha efetuado apenas parte do pagamento:

- Informe apenas o valor recebido.
- O sistema realizará uma **baixa parcial**.

Também é possível informar:

- Desconto concedido;
- Multa;
- Juros.

Após preencher as informações:

1. Clique em **Baixar**.

## Baixa parcial

Quando apenas parte do valor é recebida:

- O título permanece em aberto.
- O sistema identifica o título com a **bolinha amarela**, indicando baixa parcial.
- O saldo restante continuará pendente para recebimento.

A legenda das cores pode ser consultada pelo botão **Legenda**.

## Consultando títulos a receber

Para emitir um relatório:

Acesse:

**Relatórios → Títulos a Receber**

Na tela de filtros é possível pesquisar por:

- Período;
- Cliente;
- Forma de pagamento;
- Vendedor;
- Outros filtros disponíveis.

O relatório apresenta:

- Valor original;
- Valor recebido;
- Saldo pendente;
- Dias em atraso;
- Encargos (juros e multa, quando houver);
- Valor total ainda a receber.

## Consultando títulos vencidos

Também é possível emitir um relatório apenas com títulos vencidos.

Basta informar um período que contemple somente títulos já vencidos.

O sistema exibirá:

- Todos os títulos pendentes;
- Pagamentos parciais realizados;
- Saldo restante de cada título.

## Finalizando uma baixa parcial

Quando o cliente quitar o saldo restante:

1. Localize novamente o título.
2. Clique em **Baixar**.
3. O sistema informará que existe uma baixa parcial.
4. Confirme a visualização do histórico, se desejar.
5. Informe:
   - Banco utilizado;
   - Data do pagamento;
   - Valor restante.
6. Clique em **Baixar**.

Após a quitação total:

- O título deixa de aparecer entre os títulos em aberto.
- Passa a ser exibido como **Título Baixado** (bolinha vermelha).
- Será listado nos relatórios de títulos recebidos.

## Estornando uma baixa

Caso uma baixa tenha sido realizada incorretamente:

1. Localize o título entre os títulos baixados.
2. Selecione o título.
3. Clique em **Estornar**.
4. Confirme a operação.

O sistema irá:

- Cancelar a baixa;
- Estornar o lançamento financeiro;
- Retornar o título para a situação de **em aberto**.

:::tip
Por fim, caso tenha dúvidas ou não consiga concluir o processo, entre em contato com o suporte da Infolight.
:::
