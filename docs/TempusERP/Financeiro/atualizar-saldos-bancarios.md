# Atualizar Saldos Bancários

Essa rotina deve ser utilizada quando o cliente estiver tentando realizar uma transferência para outro caixa e o sistema informar que **não há saldo suficiente na conta bancária**.

Nesses casos, é recomendado recalcular os saldos bancários antes de tentar realizar a transferência novamente.

## Como atualizar o saldo

Acesse:

**Módulo Financeiro → Miscelânea → Calcular Saldos Bancários**

Na tela, preencha os dados da conta bancária que está apresentando a falta de saldo.

### Campos

- **Banco:** informe o banco da conta.
- **Agência:** informe a agência.
- **Conta:** informe a conta bancária.
- **Data de:** informe a data inicial do período que será recalculado.
- **Até:** informe a data final do período.

Após preencher os campos, execute o cálculo para que o sistema atualize o saldo da conta bancária.

Depois de finalizar o processo, tente realizar novamente a transferência para o outro caixa.

:::tip
Por fim, caso tenha dúvidas ou não consiga concluir o processo, entre em contato com o suporte da Infolight.
:::
