# Cadastro de cargos, funcionários e dependentes

Antes de utilizar as rotinas de Gestão de Pessoal, é necessário realizar o cadastro dos cargos, funcionários e seus respectivos dependentes.

## Como acessar

Acesse:

**Módulo Gestão de Pessoal → Cadastro**

Nesta rotina serão utilizados os seguintes cadastros:

- Cargos e Salários;
- Funcionários;
- Dependentes.

---

# Cadastro de Cargos e Salários

Acesse:

**Gestão de Pessoal → Cadastro → Cargos e Salários**

## Alterando um cargo existente

O cargo de **Motorista** já vem cadastrado como padrão no sistema.

Para atualizá-lo:

1. Selecione o cargo.
2. Clique em **Alterar**.
3. Informe o **CBO** correspondente.
4. Informe o salário do motorista.
5. Clique em **Salvar**.

> **Observação:** O cargo padrão de Motorista possui o código **100**.

## Incluindo um novo cargo

Para cadastrar um novo cargo:

1. Clique em **Incluir**.
2. Informe um código sequencial (ex.: 001).
3. Informe a descrição do cargo (ex.: Auxiliar Administrativo).
4. Preencha o **CBO**.
5. Informe o salário.
6. Preencha todos os campos destacados em azul.
7. Clique em **Salvar**.

### Botões disponíveis

- **Novo:** Salva o cadastro atual e abre uma nova tela para outro cadastro.
- **Salvar:** Salva o cadastro e encerra a tela.

# Cadastro de Funcionários

Acesse:

**Gestão de Pessoal → Cadastro → Funcionários**

Para cadastrar um funcionário:

1. Clique em **Incluir**.
2. A matrícula será gerada automaticamente pelo sistema.
3. Informe o nome do funcionário.
4. Preencha todos os campos obrigatórios (destacados em azul).

> Quanto mais informações forem preenchidas, mais completo ficará o cadastro.

## Campos de pesquisa

Sempre que um campo possuir o botão de **três pontos (...)**, significa que ele possui uma pesquisa.

Por exemplo:

- Natureza financeira;
- Cargo/Função.

Na Natureza Financeira é possível pesquisar pela descrição, digitando, por exemplo, **Salário**.

No campo **Cargo/Função**, serão exibidos todos os cargos cadastrados anteriormente.

## Situação do funcionário

No campo **Situação**, selecione o status do funcionário:

- Ativo;
- Afastado;
- Inativo.

Caso deseje, é possível cadastrar apenas funcionários ativos.

## Segunda aba — Documentação

Nesta aba devem ser informados, no mínimo:

- RG (Identidade);
- CPF.

Os demais campos podem ser preenchidos conforme a necessidade da empresa.

## Terceira aba

Preencha o campo referente ao **Grau de Instrução**, caso aplicável.

## Quarta aba

Nesta aba é obrigatório informar, pelo menos:

- Data de admissão.

Após preencher todas as informações, clique em **Salvar**.

> Caso algum campo obrigatório não tenha sido preenchido, o sistema exibirá uma mensagem informando quais informações ainda precisam ser completadas.

### Matrícula

O campo **Matrícula** pode permanecer em branco.

Caso a empresa utilize matrícula de registro dos funcionários, ela pode ser informada conforme a ficha de registro.

# Cadastro de Dependentes

Acesse:

**Gestão de Pessoal → Cadastro → Dependentes**

Para cadastrar um dependente:

1. Clique em **Incluir**.
2. Selecione o funcionário ao qual o dependente será vinculado.
3. Informe o nome do dependente.
4. Selecione o grau de parentesco (filho, enteado, etc.).
5. Informe se o dependente é incapaz, quando aplicável.
6. Preencha os demais dados necessários.
7. Clique em **Salvar**.

---

# Cadastros necessários

Para iniciar a utilização do módulo de Gestão de Pessoal, é necessário realizar os seguintes cadastros:

- Cargos e Salários;
- Funcionários;
- Dependentes.
